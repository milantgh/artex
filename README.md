artex is a multi-agent system for autonomous penetration testing in an isolated lab: a planner and workers share an asset graph and an exploration graph, with human-in-the-loop approval and full traffic recording. It ships as one binary or a Docker Compose stack. Beyond general web penetration testing, it also provides built-in CVE fingerprint detection (161 component fingerprints and 2,535 vulnerability rules) and LLM red team assessment (jailbreaking, prompt injection, data leakage, and over-permission), carried out by five specialized security expert agents.
